# Bundled specialist agents

These agent definitions are adapted from the locally supplied [ampedweb/awesome-subagents](https://github.com/ampedweb/awesome-subagents) fork of [VoltAgent/awesome-subagents](https://github.com/VoltAgent/awesome-subagents), version 2, at source revision `4ce4267485e1a5491488548b3474007e1e6bddfb`. Copyright remains (c) 2025 VoltAgent under the included MIT licence in `LICENSE`.

The bundle contains `architect-reviewer`, `qa-expert`, `typescript-pro`, `python-pro`, `golang-pro`, `rust-engineer`, `react-specialist`, `laravel-specialist`, `java-architect`, `csharp-developer`, and `rails-expert` in native Claude Code Markdown, OpenCode V2 Markdown, and Codex TOML formats. The specialist instructions retain the source expertise while removing unsupported context-manager protocols and fixed upstream model choices. They do not assume that other agents are installed.
