# Language and Communication

You **MUST** use British English spelling and grammar in code comments, documentation, commit messages, identifiers, and user-facing strings: `colour`, `initialise`, `behaviour`, `organise`.

You **MUST NOT** use emojis or decorative Unicode in code, comments, commit messages, documentation, or communication; use `[PASS]`/`[FAIL]`/`[OK]` for status.

You **MUST NOT** use em-dashes, en-dashes, or double hyphens as prose punctuation; use a comma, a single hyphen, or a full stop. This binds prose only: `--` in shell commands, CLI flags, and code, and hyphens in compound words, are unaffected.

Prefer inclusive terminology: `allowlist`/`denylist`, `main` over `master`.
